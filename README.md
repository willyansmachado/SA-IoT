# SA-IoT — Alimentador Automático

Projeto de automação desenvolvido com Arduino UNO para alimentação de animais, utilizando sensores e servo motor para controlar e monitorar a liberação de ração.

## Funcionalidades

- Identificação da aproximação do animal por sensor ultrassônico.
- Verificação da presença de ração no recipiente.
- Liberação automática de alimento por servo motor.
- Sinalização visual e sonora por LEDs e buzzer.
- Acionamento manual por botão.

## Componentes e Tecnologias

- Arduino UNO
- Linguagem C/C++
- Sensor ultrassônico HC-SR04
- Sensor LDR
- Servo motor SG90
- LEDs e buzzer
- Arduino IDE
- Tinkercad

## Objetivo

Desenvolver um alimentador automático capaz de identificar a aproximação do animal e controlar a liberação de ração, aplicando conceitos de automação, programação e Internet das Coisas.
